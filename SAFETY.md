# Safety, Security & Compatibility

Awesome webOS is a community-maintained directory of third-party resources. Listing a project is not an endorsement, security audit, or guarantee that it will work on a particular TV.

## Before installing software

- Prefer the project's canonical repository and documentation.
- Review installation instructions, permissions, dependencies, and source code when available.
- Check whether the package is maintained and whether issues report relevant security or compatibility problems.
- Avoid installing packages from unknown mirrors when an official source is available.
- Back up important settings where possible and understand the recovery process before making system changes.

## Rooting and firmware modification

Root access and firmware modifications can increase device-control options, but they also increase risk.

Potential consequences include:

- Loss of settings or data
- Unstable behavior or loss of functionality
- Exposure of services or credentials
- Difficulty applying official updates
- A device that requires recovery or may become unusable

Before proceeding, verify the exact TV model, region, webOS version, and firmware compatibility using current project documentation. Do not assume that instructions for one model or firmware apply to another.

## Network and privacy tools

DNS filtering, telemetry controls, and ad-blocking tools may affect more than the intended service. They can break app sign-in, content playback, updates, or other TV features. Apply changes incrementally and keep a record of settings so they can be reversed.

A project claiming to improve privacy is not necessarily safe or comprehensive. Review what it changes and what traffic it can observe or modify.

## Compatibility labels

If compatibility information is added to this list, it should be evidence-based:

- **Tested:** a specific model and software version were tested by a contributor.
- **Reported:** a community member reports that it works, but the list maintainers have not independently verified it.
- **Unknown:** there is not enough reliable information to make a claim.

Do not label a project “safe,” “secure,” or “compatible with all TVs” without strong evidence.

## Responsible disclosure

If you find a vulnerability in a listed project, contact its maintainers privately through their published security-reporting channel when available. Avoid publishing exploit details that could put users at risk before maintainers have had a reasonable opportunity to respond.
